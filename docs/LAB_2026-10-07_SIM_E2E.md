# Lab 2026-10-07: the natural-language pick, end to end, in simulation

**Goal:** run "pick up the red block" through every real software layer
(language parser → orchestrator → perception node → MoveIt → trajectory
controller) with no robot and no camera, check the failure paths as well as
the happy path, and fix whatever does not work. Nikola runs every command
himself. This file is the plan; fill in the **Results** table as you go.

What "simulation" means here is **sim tier 1** (mock hardware, see
[SIMULATION.md](SIMULATION.md)). The arm is ros2_control mock hardware, the
camera is a rendered still image, and the gripper is `FakeRg2`. Everything
in between is the code that ran on the arm on 2026-10-02. This proves the
software chain and that the plans are reachable. It does **not** prove grasp
quality or calibration; those are lab results.

## Step 4: the full pipeline, scripted (10 min)

```bash
bash scripts/lab_pick_rehearsal.sh
```

It starts the mock driver, MoveIt (KDL), the perception node on the rendered
scene, and the fake status node. It waits until each one is ready, then
runs six sentences through `scripts/lab_pick.py`:

| Sentence | Expected | What it proves |
|---|---|---|
| pick up the red block | `succeeded / ok` | the whole chain, every stage |
| put the red block on the blue block | `succeeded / ok` | pick-and-place: two detections, place height |
| pick up the green block | `failed / not_found` | re-observe once, then a courtesy HOME |
| go up 2 cm | `refused / action_not_allowed` | a jog is not a pick; no motion |
| pick up the red block and throw it | `refused / target_not_noun_phrase` | validator refusal; no motion |
| pick up the red block (lab workspace) | `failed / outside_workspace` | the lab plate gate in LOCATE |

The summary prints PASS/FAIL per line, and the exit code is 0 only if all pass.
Logs go to `/tmp/lab-pick-rehearsal/<timestamp>/`:
`driver.log`, `moveit.log`, `perception.log`, `scenario-N.log`, `runs/*.jsonl`.

One sentence only: `bash scripts/lab_pick_rehearsal.sh "pick up the blue block"`.

### Findings from the session

1. **Wrong shell.** A `!`-prefixed command in Claude Code runs on the host,
   not in the devcontainer. Check `whoami; pwd` → `ros`, `/workspaces/AI_arm`.
2. **Devcontainer terminals start on domain 42.** The image's `~/.bashrc`
   exports `ROS_DOMAIN_ID=42` (to match the Jetson). A T5 left on 42 saw no
   `/joint_states`: `OBSERVE … JogError('No fresh joint state -- is the driver
   running?')`. Fix: the `export ROS_DOMAIN_ID=87 ROS_LOCALHOST_ONLY=1 …` line
   first in **every** terminal. The rehearsal refuses 42; the by-hand path
   does not.
3. **Gap 8: plan-only cannot pass PLAN from a fresh mock arm.** PLAN reads the
   live joint state (`lab_pick.py` `plan()`), and in plan-only the OBSERVE move
   to `ready` is planned but not sent, so the tool is still horizontal. Run one
   `--execute` pick (or move to `ready`) first. On the real arm this never
   shows, because sessions start parked at `ready`.
4. **RViz shows no objects in tier 1.** The blocks exist only in
   `/tmp/sim/scene.png` + `table.json`; nothing publishes them as markers or
   collision objects. The arm does go to the located point (check with the TF
   display or `tf2_echo base_link tool0`). Visible objects need tier 3.
5. **`.venv` was active** in T5. It worked, but ROS nodes should use the
   container's system Python; `deactivate` to rule it out.
6. `selected interface "lo" is not multicast-capable` is expected with
   `ROS_LOCALHOST_ONLY=1` (Cyclone falls back to unicast). Not an error.
7. **Tier 3 docs disagree.** `src/ur7e_gazebo/README.md` says the grasp latch
   does not attach; `TASK2_SOFTWARE.md` says the Gazebo demo ends holding the
   object. Also, gap 7 is partly out of date: `scripts/pick_place_language_demo.py`
   (TASK3_SOFTWARE.md) does use the language parser in Gazebo, but not the
   orchestrator / `lab_pick.py`. Next session: run
   `ros2 launch ur7e_perception gazebo_demo.launch.py` to settle it.

## If something fails

| Symptom | Likely cause / do |
|---|---|
| `TIMEOUT … waiting for …` | The log tail printed under it is the real error. Usually the workspace was not built or sourced |
| `Failed to find a free participant index` | That shell has no `CYCLONEDDS_URI` (Step 5 exports) |
| `BLOCKED … execution gate closed` / `pendant speed` | `rehearsal_status.py` is not running, or mock hardware's own status broadcaster is overriding it. Check with `ros2 topic echo /speed_scaling_state_broadcaster/speed_scaling` |
| PLAN fails `unreachable` after several runs | Mock-hardware wrist wind-up (SIMULATION.md). Restart T1 |
| Planning fails "invalid bounds" / 99999 | wrist_3 is past the lab cap of ±6.133 rad (LAB 10-06). Restart T1 |
| `outside_workspace` on the happy path | The `--workspace` flag is missing |
| `perception_error` instead of `not_found` | The node's reason text changed. Compare it with the `missing` list in `LabAdapters.detect` |
