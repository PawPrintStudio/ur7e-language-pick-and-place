# Ro - Boko brand sources

Checked October 13, 2026. This is a custom local robot dashboard, informed by
Texas State's official design guidance, not an official Gato template or a
claim of university brand approval.

- [Official templates](https://brand.txst.edu/resources/templates.html): Canva,
  PowerPoint and Gato options. The local dashboard retains its simple layout.
- [Current logo system](https://brand.txst.edu/visual-identity/our-university-logo-system.html):
  the university star and wordmark were updated; the TXST acronym was unchanged.
- [Logo usage](https://brand.txst.edu/visual-identity/our-university-logo-system/usage.html):
  the complete transparent gold-and-white 2025 university mark appears unchanged
  on maroon, separate from the tool title. Original SVG from TXST's homepage:
  https://www.txst.edu/.resources/1786806000000/txstprimarygoldwhitelogo2025.svg
  A source copy is retained in `txst-primary-gold-white-2025.svg` and embedded in
  the dashboard for offline use. This replaces the earlier white-backed JPEG.
- [Colors](https://brand.txst.edu/visual-identity/colors.html): Texas State Maroon
  `#501214`, Bright Gold `#D7BD8A`, Dark Gold `#AC9155`, web Sandstone `#F5F1EE`,
  and Charcoal `#363534` for text. Status colors remain distinct from decoration.
- [Typography](https://brand.txst.edu/visual-identity/typography.html): Arial,
  the university's recommended web-safe alternative, with Helvetica/sans-serif
  fallbacks. Public Sans embeds were removed following presentation feedback;
  the earlier font license is retained for provenance.

The university logo is a university trademark, not covered by the font license.
No logo shapes or wording were generated or modified. The camera stream is
unchanged; colors in the real computer-vision overlay remain functional labels.
